System Power
These actions immediately affect gateway connectivity. Halt requires physical or remote power access to bring the system back online.
Reboot Gateway
Restarts the system. All connections will drop for 1-2 minutes.
Halt (Power Off) Gateway
Shuts down the system completely. Requires physical/remote power to restart.
Factory Reset
This ERASES all firewall rules, network assignments, VPN configuration, and panel credentials, returning the gateway to its just-installed state. The system reboots automatically afterward. This cannot be undone.
Reset to Factory Defaults
All configuration will be lost. A new admin password will be generated on next boot.
